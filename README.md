
# Student Management Portal

## Subject
26CS102 - Foundation of Full Stack

## Project Description
The Student Management Portal is a simple static website
developed using HTML5 and CSS3.

## Objectives
- Create a student portal homepage.
- Display information about the portal.
- Provide a student registration form.
- Display available courses.
- Provide contact information.

4. Courses
5. Contact
